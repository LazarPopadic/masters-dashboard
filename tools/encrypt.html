Encrypt the dashboard data (runs only on your Mac)

Use this whenever data.source.js changes, or to change the password. Open this file locally — it loads ../data.source.js, encrypts it with your password, and gives you a new data.encrypted.js.

  1. Open this file by double-clicking it (it must sit in the tools/ folder next to data.source.js).
  2. Type the password you want the website to ask for.
  3. Click Encrypt & download and replace js/data.encrypted.js with the downloaded file.
  4. Commit and push — only the encrypted file ever goes to GitHub.
